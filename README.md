# 南京崴肯自动化 · 精密工业官网与 WebGIS 空间运维平台（v4.1）

面向汽车被动安全非标自动化设备制造企业（安全气囊、安全带生产与试验设备、3D 视觉与工业机器人）打造的**企业官网 + 自研 WebGIS 空间运维与车间数字孪生工作台**，纯原生 HTML5 / CSS3 / Canvas 2D / Vanilla ES6 零外部依赖构建，离线/在线均可秒开，适合作为 WebGIS 与前端可视化方向的核心简历作品集项目。

## 核心 WebGIS 工程亮点

1. **自研无依赖 WebGIS 空间渲染引擎（`js/webgis-engine.js`）**
   - **严密投影体系**：手写 `WGS84 (EPSG:4326)` ⇄ `Web Mercator (EPSG:3857)` 正反解、Slippy Map 世界像素空间（`256 × 2^z`）以及纬度补偿动态比例尺计算（`156543.03 * cos(lat) / 2^z`）。
   - **混合矢量 + XYZ 瓦片金字塔架构**：内置长三角四省市（苏/皖/浙/沪）行政边界与长江/太湖水系 RFC 7946 GeoJSON 矢量底图（离线秒开、零裂片），同时支持一键叠加在线 CartoDB `z/x/y` 栅格瓦片金字塔与 LRU 内存瓦片缓存。
   - **空间分析与制图算法**：
     - **球面测地缓冲区分析（Geodesic Buffer）**：基于球面目标点公式生成真球面多边形（非欧氏失真圆），拖动半径滑块（`50–350 km`）实时执行空间落点检索并统计工程响应覆盖率。
     - **Haversine 大圆测地测距工具**：交互式多点标定，实时计算分段距离与累计总长（宏观视图 `km` / 车间视图 `m`）。
     - **高斯 KDE 核密度热力图层**：离屏 Canvas 渲染加权核密度场并叠印至地图视口。
     - **平滑相机动画与要素拾取**：支持光标锚点无级滚轮缩放、拖拽漫游、三次缓动 `flyTo` 飞行定位，以及宏观点拾取 + 微观 **Ray-Casting 射线法点面拾取（Point-in-Polygon）**。
2. **宏观地理 ⇄ 微观车间双尺度空间下钻（`gis.html`）**
   - 支持从长三角交付基地（南京总部 / 芜湖金安世腾 / 江苏锦恒）一键下钻至 **车间米制平面 Indoor GIS（`EPSG:Local`, `28m × 16m`）**。
   - 呈现 `ST01–ST05` 气囊整线与安全带焊接岛多边形、安全光栅电子围栏（Geofence）、AGV 物流巡航拓扑与工位节拍负载热力图。
   - 内置 **RFC 7946 GeoJSON 在线查看与一键导出**（含实时生成的球面缓冲区多边形）。
3. **工业自动化交互与精密视觉系统**
   - **Canvas 2D 3D 视觉点云视窗**：透视投影 + Z-sorting + 鼠标拖拽轨道旋转 + 3 套工业点云模型实时切换。
   - **MES 零件 ⇄ 总成双向追溯状态机**：正向追溯 / 反向溯源视图与防错拦截（NG Hold）全流程模拟。
