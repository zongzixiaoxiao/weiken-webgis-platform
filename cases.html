安全气囊 CASE-01 · 柔性整线

DAB / KAB 柔性安全气囊生产线

集成热熔焊接机、叠袋机、饰盖压装机、拧紧机与电性能检测机；具备极强防错能力，并支持 D/P/S/C 多种气囊柔性混线。

工序/工装/传感器三重防错 零件 ⇄ 总成双向追溯 自动打印总成码/箱码 D / P / S / C 柔性兼容
安全气囊 CASE-02 · 自动倍速链

DAB 安全气囊自动线（ST40~70）

倍速链自动流转架构（PAB 自动线同类结构），将发生器双枪自动拧紧、机器人电性能检测与喇叭按压力检测无缝串联。

双枪自动拧紧发生器螺母 视觉引导机器人电检 自动喇叭按压力检测 自动下料 + 整线追溯
安全气囊 CASE-03 · 热成型专机

DAB 气袋热成型设备（三工位）

用于气袋折叠后热压定型，大幅压缩气袋体积以便装配入壳体，自动完成「热成型 → 冷却 → 机械手下料」闭环。

热压前75 mm 热压后48 mm 并行3 工位同步
三工位同时进行提效 热成型-冷却-自动下料
安全带生产 CASE-04 · 四工位转盘

钢丝绳压铆机（四工位转盘）

交付宁波华力兴等客户，四工位精密转盘集成伺服压铆监控、全数预拉伸与双目视觉复检，确保安全带钢丝绳连接零缺陷。

压力-位移实时监控存盘 在线 100% 预拉伸测试 尺寸与到位视觉检测 OK / NG 自动分拣
安全带生产 CASE-05 · 锁扣倍速链

安全带锁扣生产线（倍速链）

整线尺寸 2880×1150×1900mm，按产品工艺可选超声波焊接或自动打螺丝，覆盖力/电/视觉/激光全工序闭环。

超声焊接 / 自动拧紧可选 插入力/打开力/导通检测 漏焊检测 + 激光打标 自动拔线束 + NG 分拣
安全带检测 CASE-06 · 在线全检一体机

安全带车带感角度检测一体机

在线同步完成车感、带感、AB/CD 四向角度、总带长与噪音检测，上位机实时绘制 G 值—位移曲线并联网上传追溯。

车感0.45g ≤50mm 带感0.8g不锁 / 2.0g锁止 角度12° / 27° 节拍13–15 s
安全带生产 CASE-07 · 卷簧绕簧专机

卷簧板 / 罩壳 / 绕簧一体机

四工位转盘高度集成卷收器核心储能结构装配：工位1上料 → 工位2压装卷簧组件 → 工位3机械手移载罩壳 → 工位4压装同步绕簧。

四工位转盘节拍并行 机械手精准移载罩壳 压装与设定圈数同步绕簧 双手安全启动 + 光栅防护
安全带生产 CASE-08 · 缝纫自动化

带头 / 织带结自动翻折缝纫机

替代传统人工手工折带，通过精密定位气缸模组自动翻折并送入花样缝纫机，兼顾尺寸一致性与高生产效率。

翻折尺寸高重复精度 缝纫花样尺寸稳定 大幅降低操作劳动强度 支持带头 / 织带结机型
试验设备 CASE-09 · G 值测试

G 值试验机（G Lock Tester）

面向安全带研发验证与品质抽检，高精度测试卷收器车感（AS）及带感（WS）动态加速度触发锁止性能。

车感 (AS) 加速度锁止测试 带感 (WS) 加速度锁止测试 全封闭安全防护观察罩 试验曲线自动记录存盘
试验设备 CASE-10 · 卷收器耐久

三工位卷收器疲劳 & 倾斜锁止试验机

3 工位并行开展卷收器耐久疲劳测试，自由设定车感/带感锁止频次；同步提供符合国标及主机厂企标的倾斜锁止试验机。

工位3 并行 速度≥30 次/min 角度0°–40° 可调 标准GB14166-2013
试验设备 CASE-11 · 锁扣耐久

三工位锁扣疲劳试验机

3 只安全带锁扣同步执行高循环插拔寿命试验，自动判定力学与电导通合格性，到达设定次数自动停机保存报表。

3 工位同步疲劳测试 插入力 / 开启力阈值设定 测试全程线束导通监控 自动判定 + 历史数据查询
方向盘产线 CASE-12 · SW 整线

方向盘装配生产线（ST10~ST60）

全长 10000mm 的模块化方向盘装配线，覆盖卡簧、多功能按键、下护罩装配及电性能总检包装全流程。

零件信息全流程条码追溯 拧紧力矩与电性能存储 ST10~ST60 严格过程防错 配料架与中转工台联动
